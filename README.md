# MCP (Middleware Control Plane)

This repository handles all external integrations for the ServiceDesk AI platform.

## Responsibilities
- Database interactions (CRUD, queries)
- External API integrations
- Third-party service communication
- Centralized service orchestration

## Architecture
- Modular service design
- Scalable integration layer
- Used by: servicedeak-ai

## Tech Stack
- Python / FastAPI
- REST APIs
- Database connectors

## Usage
Used as a backend integration layer for the main AI system.
